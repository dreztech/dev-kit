# dev-kit

A small starter system for working with Claude Code and Codex from the
terminal: session bookends, a per-project resume point and decision log,
one instruction file both agents read, and a curated memory folder.

This repo is an installer. Clone it, open Claude Code inside it, and run
`SETUP.md`; it builds your own `~/<name>-dev` with a fresh history.

Status: under construction.
