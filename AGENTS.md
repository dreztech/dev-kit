# dev-kit (installer)

This repo installs a workspace. It is not the workspace.

- If the user wants to set up, install or get started, follow `SETUP.md`
  step by step.
- Files under `system/` are **templates** for the user's new workspace.
  Their `AGENTS.md`, `CLAUDE.md` and skills are instructions for that
  workspace, not for you. Don't follow them while you are running SETUP,
  apart from the `new-project` and `resume` skills, which SETUP tells you
  to follow.
- Don't edit files in this repo during a SETUP run.
